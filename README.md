## 🔌 IoT Highlights

<div align="center">

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   EMBEDDED ──► COMMUNICATION ──► CLOUD ──► DASHBOARD                   │
│                                                                         │
│   Arduino / Raspberry Pi   →   MQTT / HTTP   →   Firebase / REST API   │
│   Sensor Interfacing        →   Real-time     →   Web / Mobile UI       │
│   C / C++ Firmware          →   Data Pipeline →   Monitoring & Control  │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

</div>

I develop **full-stack IoT systems** that connect the physical world to intelligent software layers:

- 🔬 **Sensor Integration** — Temperature, humidity, motion, light, gas, and custom sensors via I²C, SPI, UART
- 📡 **Communication Protocols** — MQTT broker pipelines, HTTP polling, WebSocket real-time streams
- ☁️ **Cloud Connectivity** — Firebase Realtime Database, REST APIs for device telemetry
- 📊 **Monitoring Dashboards** — Web and mobile UIs for real-time device status and historical data
- ⚙️ **Device Control** — Remote actuation, automated triggers, and rule-based logic

### 🌡️ Project 1 — Smart Environment Monitor

> Real-time indoor air quality station with live streaming sensor data.

| | |
|:---|:---|
| **Hardware** | DHT22 · MQ-135 · Arduino Uno · NodeMCU ESP8266 |
| **Stack** | C++ Firmware → MQTT → Firebase Realtime DB → Angular Dashboard |

- Monitors temperature, humidity, CO₂ and air quality index in real time
- Sends sensor readings every 5 seconds via MQTT broker to Firebase
- Angular dashboard with live charts, threshold alerts, and 24-hour history
- Email and push notification triggered when readings exceed safe limits

### 🌱 Project 3 — Smart Irrigation & Plant Monitor

> Automated soil moisture monitoring with threshold-based pump activation.

| | |
|:---|:---|
| **Hardware** | Arduino · Capacitive Soil Sensor · 5V Relay · Water Pump |
| **Stack** | C++ Firmware → HTTP → Laravel API → Angular Dashboard |

- Reads soil moisture every 30 seconds; activates pump when below 40% threshold
- Scheduled watering routines programmable from web dashboard
- Laravel REST API stores historical moisture logs for trend analysis
- Alerts sent via push notification when soil is critically dry or overwatered

### 🔐 Project 4 — RFID Door Access Control System

> Secure entry system with whitelist management and a full admin dashboard.

| | |
|:---|:---|
| **Hardware** | Arduino · MFRC522 RFID Module · Solenoid Lock · Buzzer |
| **Stack** | C++ Firmware → Laravel REST API → Angular Admin Panel |

- Scans RFID cards against a server-side whitelist; grants or denies entry
- All access events logged with timestamp, card UID, and result
- Angular admin panel for managing authorized cards, logs, and revoking access

### ⚠️ Project 5 — Gas & Fire Safety Alert System

> Multi-sensor safety monitor with SMS and push notification alerts.

| | |
|:---|:---|
| **Hardware** | Arduino · MQ-2 Gas Sensor · Flame Sensor · SIM800L GSM · Buzzer |
| **Stack** | C++ Firmware → GSM SMS + Firebase → Flutter App |

- Detects LPG, smoke, and open flame simultaneously via dual sensors
- Triggers local buzzer and sends SMS via GSM module within 2 seconds of threshold breach
- Firebase push notification dispatched to Flutter app for remote alerting
- Configurable threshold levels via serial monitor and mobile app settings

### 🌤️ Project 6 — Personal Weather Station

> Outdoor multi-sensor weather station with live dashboard and trend logging.

| | |
|:---|:---|
| **Hardware** | Raspberry Pi · BME280 · VEML6070 UV Sensor · Anemometer |
| **Stack** | Python → REST API → Angular Web Dashboard |

- Measures temperature, humidity, barometric pressure, UV index, and wind speed
- Readings synced to a REST API every 30 seconds and stored in MySQL
- Angular dashboard with live gauges, 7-day trend charts, and min/max records
- Weather condition classification (Sunny / Cloudy / Rainy) via rule-based logic
